\section*{Question 1}
\textbf{Q1.} Find the value of $c$ and $n_0$ such that $f(n)=\sqrt{n}$ is $\Omega(\log n)$.

\textbf{Solution. } To show that $f(n) = \sqrt{n}$ is $\Omega(\log n)$, we need to find positive constants $c$ and $n_0$ such that for all $n \ge n_0$, the inequality holds:
$$0 \le c \cdot \log (n) \le \sqrt{n}$$
I choose $c = 1$ as a convenient constant. \\
Now we need to find an $n_0$ such that $\log_2 n \le \sqrt{n}$ for all $n \ge n_0$.
If we chose $n=16$, we have $\log_2 16 = 4$ and $\sqrt{16} = 4$, so the inequality $4 \le 4$ holds.\\
Since both the functions are strictly increasing function in the domain of $n>1$, if we chose $n=25$, the inequality $1 \cdot 2.3219 < 5$, meaning $n = 4$ is the lowest point where this inequality holds.    
Thus, we can choose $c = 1$ and $n_0 = 16$ as the answer. 

\begin{finalanswer}
Final choice: $c=1$ and $n_0=16$
\end{finalanswer}

\section*{Question 2}
\textbf{Q2.} Find the value of $c_1$, $c_2$ and $n_0$ such that $f(n)=10n^2-3n$ is $\Theta(n^2)$

\textbf{Solution. } Show constants $c_1,c_2,n_0$ such that $f(n)=10n^2-3n$ is $\Theta(n^2)$. \\

We have to show that for some $n_0$, $c_1$ and $c_2$, 
\[
  c_1 n^2 \le 10n^2 - 3n \le c_2 n^2
\]

Keeping $n_0$ as 1,  for $n \ge 1$, the function $f(n)$ is positive.
Dividing the inequality by $n^2$:
$$c_1 \le 10 - \frac{3}{n} \le c_2$$
Lower Bound ($c_1$): For $n \ge 1$, the expression $10 - \frac{3}{n}$ is at its minimum when $n=1$. The minimum value is $10 - 3 = 7$. We can choose $c_1 = 7$. \\
Upper Bound ($c_2$): For any $n>0$, the expression $10 - \frac{3}{n}$ is always less than 10. We can choose $c_2 = 10$. \\

\begin{finalanswer}
$c_1=7,\ c_2=10,\ n_0=1$, so $10n^2-3n = \Theta(n^2)$.
\end{finalanswer}
